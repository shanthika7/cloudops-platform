CloudOps Platform

Workload Application: Java Spring Boot Banking Application

Project Overview
CloudOps Platform is a production-oriented DevOps platform built on AWS to demonstrate automated infrastructure provisioning, secure CI/CD, containerized application deployment, code quality enforcement, security scanning, and cloud monitoring.

The platform uses a Spring Boot banking application as the workload, while the primary focus is the DevOps and platform engineering surrounding the application.

Implemented Capabilities
Infrastructure as Code using Terraform
Containerized Spring Boot application using Docker
Automated CI/CD using GitHub Actions
SonarQube Quality Gate
Trivy container vulnerability scanning
Amazon ECR image management
Amazon ECS/Fargate deployment
Application Load Balancer with health checks
AWS Systems Manager Parameter Store for application secrets
CloudWatch logging and ECS monitoring
Automated post-deployment health verification
